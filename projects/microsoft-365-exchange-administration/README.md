### Mailbox Forwarding vs. Inbox Rules

Mailbox forwarding and inbox rules serve different purposes:

- **Mailbox forwarding:** Routes incoming messages to another configured address.
- **Inbox rules:** Apply defined actions to messages that meet specified conditions, such as forwarding selected messages.

These settings should be configured only with appropriate authorization and according to the organization's email and data-handling policies.

## Security and Best Practices

- Verify the target account before resetting passwords or changing account status.
- Disable accounts only when authorized and when the action is appropriate.
- Follow approved procedures for account recovery and password resets.
- Grant mailbox permissions according to business requirements.
- Configure forwarding and inbox rules only with appropriate authorization.
- Review group membership and administrative permissions carefully.
- Avoid sharing student information, passwords, mailbox contents, or sensitive configuration details.
